How offline playback works

  • Saved on this device only. Nothing is uploaded, and the lecture is not re-hosted anywhere — the same bytes the player streams are written into your browser's own storage.
  • No expiry. A signed stream link dies in minutes; a saved lecture carries its own key and media, so it does not care what the signer is doing tomorrow.
  • It plays here. Play offline opens the lecture in this site, out of this browser's storage — no server, no signed link, nothing to expire. Save file is there when you want a copy in your Downloads folder to carry to VLC or another phone.
  • Two formats. Most downloads are plain MPEG-TS (.ts), which plays anywhere. If the source only offers a keyed playlist, the saved copy is a self-contained .m3u8 — the key travels inside it.
  • Interrupted is not lost. A lecture that stops halfway stays playable up to that point and resumes from the same place.
  • Long lectures arrive in parts. A two-hour class is downloaded in slices and stitched into one file once it finishes.
